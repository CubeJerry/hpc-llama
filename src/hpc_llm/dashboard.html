GPU sessions

Closing a browser tab does not stop its GPU job. Use Stop job when finished. Native llama.cpp chat has its own conversation history and settings.

Workspace files

Browse, edit and save files on the cluster here. To use one in native chat, download it and attach it in the chat tab. Use Draft with model to generate a file, review the text, and save it to an exact path.

Text editing: up to 2 MiB. Upload and download: up to 32 MiB. Use model installation for large model files.

This launcher runs as your cluster account. GPU jobs remain active if the launcher disconnects.
